# v0.21.2

## Dependency update

- `@hono/node-server`, a transitive dependency of `@modelcontextprotocol/sdk`, is updated from 2.0.11 to 2.1.5 in `package-lock.json`. This fixes [GHSA-rmxm-3fg6-px4f](https://github.com/advisories/GHSA-rmxm-3fg6-px4f) (CVE-2026-118663, medium): `serveStatic` decoded the request path a second time, which could bypass middleware on static paths.

This server was not affected: it uses only the stdio transport and never loads the SDK's Streamable HTTP server or `serveStatic`. `package.json` is unchanged, because 2.1.5 is within the SDK's allowed range (`^1.19.9 || ^2.0.5`), so new installs could already resolve a fixed version. This release makes the fixed version the tested baseline.

Scanning behavior, responses and the pinned OSV-Scanner 2.7.0 are unchanged from v0.21.1.

## Verification

- Automated tests (1340), type check, and build
- Dependency audit (`npm audit`) and OSV-Scanner scan of the project: no findings
- GitHub Actions passed on Node.js 20, 22, 24 and 26, including the OSV-Scanner job

npm publication is separate from this GitHub release.
