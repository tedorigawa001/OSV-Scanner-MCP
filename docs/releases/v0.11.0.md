# v0.11.0

## English Tool Descriptions, Messages, and Documentation

All text shown to users and to LLM clients is now in English:

- Tool titles, descriptions, and argument descriptions
- Human-readable text in responses: `upgrade_note`, `update_hint`, `coverage.warning`, the reasons and hints in `coverage` (missing lockfiles, unscannable requirements, skipped files, inferred coordinates), and the parent POM warnings
- Error messages (`error.message`) for every error kind
- Startup warnings and log messages on stderr

Field names and enumerated values were already in English and are unchanged, so clients that parse the responses are not affected. Clients that matched on the previous Japanese message text need to be updated.

The README and SECURITY.md are now in English. The README was also brought up to date: the features list now covers `suggest_fix` and direct/transitive dependencies, the network section covers `requirements.txt` and the OSV check of recommended versions, the `suggest_fix` output example reflects the current fields, and the error table lists every error kind.

## Other Changes

- The concurrent scan limit message now reads "The concurrent scan limit (N) has been reached".

npm publication is separate from this GitHub release.
