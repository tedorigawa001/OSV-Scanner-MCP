# v0.3.2

## Security Dependency Update

- Update the locked transitive dependency `fast-uri` from 3.1.7 to 3.1.8, addressing [GHSA-hrr3-gc8f-f4qj](https://github.com/advisories/GHSA-hrr3-gc8f-f4qj).
- The dependency is used through `@modelcontextprotocol/sdk` and `ajv`.
- No MCP tool API or configuration changes.

The advisory concerns inconsistent host case normalization for percent-encoded scheme-relative URLs. The dependency-level issue was reproduced before updating and no longer reproduced after updating. Exploitability through this MCP server has not been established.

## Installation Note

This update records the patched dependency in the repository lockfile. npm consumers resolve transitive dependencies using their own installation state; this repository's lockfile does not force existing installations to update. Refresh the affected dependency in the consuming installation and confirm that `npm ls fast-uri` reports a patched version (3.1.8 or later in the 3.x line).

npm publication is separate from this GitHub release.
