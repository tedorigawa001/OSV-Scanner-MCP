# v0.24.3

## Dependency update

- `koffi`, the runtime dependency used to confirm the real path of an opened file on macOS and Windows, is updated from 3.3.7 to 3.3.8 and remains pinned exactly. The native file boundary tests passed on Linux, macOS and Windows with Node.js 22 and 26

Scanning behavior, responses and the pinned OSV-Scanner 2.7.0 are unchanged from v0.24.2.

## Development

- GitHub Actions in CI are updated through Dependabot and remain pinned to commit SHAs: `actions/checkout` 7.0.1, `actions/setup-node` 7.1.0 and `google/osv-scanner-action` 2.7.1
- Research validation records in `docs/validation` bind the exact `package.json` and `package-lock.json` bytes they were measured with. The version bump in this release makes them differ at HEAD again, as described for v0.23.0

## Verification

- Automated tests (product scope: 3,189 passed), type check and build
- Dependency audit: `npm audit` and OSV-Scanner 2.7.0 on `package-lock.json` report no findings
- GitHub Actions passed on Node.js 22, 24 and 26 on Linux, macOS and Windows, including the OSV-Scanner job

npm publication is separate from this GitHub release.
