# v0.21.1

## Tool description

- The `scan_project` description now lists `poetry.lock` (lock versions 1.1, 2.0 and 2.1) and `pdm.lock` (lock versions 4.0–4.5.1) among the formats with `dependency_relation`, and briefly explains how Poetry and PDM determine `declared_in`, `introduced_by` and child coverage. v0.21.0 added this support but did not mention it in the description, so clients reading the tool description were not told they could rely on these fields for Poetry and PDM.

Scanning behavior, responses and the pinned OSV-Scanner 2.7.0 are unchanged from v0.21.0.

## Verification

- Automated tests (1340), type check, and build
- Through MCP: `tools/list` returns the updated `scan_project` description
- GitHub Actions passed on Node.js 20, 22, 24 and 26, including the OSV-Scanner job

npm publication is separate from this GitHub release.
