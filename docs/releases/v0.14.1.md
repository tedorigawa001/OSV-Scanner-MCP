# v0.14.1

## Development Environment

- Update the development Node.js version to 26.12.1 in `.node-version` and document it in the README.
- Add Node.js 26 to the CI matrix alongside Node.js 20, 22, and 24.
- Update the development dependency ranges for `@types/node` to 26.6.5 and Vitest / `@vitest/coverage-v8` to 5.0.5, with the corresponding lockfile updates. TypeScript remains at 7.0.2.

The minimum runtime requirement remains Node.js 20.19. This patch updates the development environment and release version; scanning behavior and the pinned OSV-Scanner 2.7.0 are unchanged.
